# ОЗУ — портал угруповань

Окрема система для ОЗУ (банди, мафія, угруповання): окрема БД, жодного звʼязку з державними даними. Публічні «вуличні новини», карта районів, сторінки угруповань, набір; кабінет угруповання з шифрованим каналом, складом і общаком; спільна підпільна дошка: райони, війни, замовлення; адмінпанель.

## Локальний запуск
```
npm install
npm start            # http://localhost:3200  (PORT=… щоб змінити)
```
Без `DATABASE_URL` використовується SQLite у `data/`. З `DATABASE_URL` — Postgres (схема створюється автоматично).

Демо-акаунти (пароль `demo1234`, усі позначені «[Приклад]»): demo_admin, demo_boss (лідер Ballas), demo_ballas (учасник), demo_ballas2, demo_grove, demo_don (Синдикат), demo_vagos
Вимкнути демо: `SEED_DEMO=0`. Перший справжній адмін: `ADMIN_LOGIN` + `ADMIN_PASSWORD`.

## Деплой на Render
1. Створити репозиторій на GitHub і запушити: `git remote add origin … && git push -u origin master`.
2. Render → New → Blueprint → обрати репозиторій (`render.yaml` вже є).
3. Задати `DATABASE_URL` (окрема Postgres БД!), `ADMIN_LOGIN`, `ADMIN_PASSWORD`.

## Ролі
- Гість: вуличні новини, карта районів, угруповання, заявка на вступ.
- Учасник: кабінет свого угруповання (канал, склад, общак — перегляд), дошка районів/війн, взяття замовлень інших угруповань, анонімні новини.
- Лідер (роль leader або передостанній ранг+): видача доступу/заявки, ранги, вигнання, записи в общак, профіль і набір, захоплення вільних районів, оголошення війни/капітуляція (район переходить переможцю), замовлення.
- Адмін: користувачі, нові угруповання й райони, завершення воєн, журнал.

## Вхід через ігровий акаунт NovaRP

Портал звертається до сервісу `nova-auth` (окремий репозиторій/папка, працює на ПК з сервером гри, слухає лише 127.0.0.1:3901, тільки SELECT).
Назовні сервіс виставляється через Cloudflare Tunnel (HTTPS), кожен запит має заголовок `x-auth-secret`, є ліміт спроб (IP і логін).

| Env | Значення |
|---|---|
| `NOVA_AUTH_URL` | https-адреса тунелю |
| `NOVA_AUTH_SECRET` | спільний секрет (= `AUTH_SECRET` у nova-auth) |
| `AUTH_MODE` | `nova` (лише гра + `ADMIN_LOGIN`), `both`, `local` |
| `NOVA_ADMIN_LEVEL` | мін. `admin_level` у грі для адміна порталу (типово 1) |
| `GROUP_MAP` | відповідність кодів гри → портал |

Доступ і ранг синхронізуються при кожному вході. Немає відповідної фракції — дружня відмова. Кілька персонажів — вибір персонажа. Заблокований акаунт гри — відмова.
